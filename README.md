1. Skapa ett Git-repo där ni bjuder in samtliga medlemmar. I er huvudbranch skapar ni ett React-projekt. Installera alla dependencies redan nu (t.ex React Router), ta bort onödig kod (t.ex I App.jsx) och filer ni ej kommer använda (loggor osv.).


2. Skapa sedan varsin branch från huvudbranchen.



3. Varje person i teamet väljer nu en av följande saker

- Todo-list (Lägg till så mycket funktionalitet som ni hinner - Utföra todos, ta bort todos, redigera etc).

- En miniräknare (två eller fler fält med möjlighet att addera/multiplicera/dividera/subtrahera dessa med varandra)

- Användarlista.(Lägg till så mycket funktionalitet som ni hinner - Lägga till, ta bort, filtrera, sortera etc.)

Slå nu ihop samtliga brancher till main en i taget och se att allt fungerar och ser bra ut!
